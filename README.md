# AerialMind-X

**An Adaptive Vision-Based Agent for Autonomous Drone Navigation with Dynamic Obstacle Avoidance and Goal-Directed Replanning**

## Overview

AerialMind-X aims to develop an autonomous navigation prototype that combines visual perception, obstacle-aware path planning, dynamic obstacle avoidance, and goal-directed replanning.

## Core Modules

- Perception: image processing and obstacle detection
- Planning: global path planning using A\*
- Control: navigation decisions and movement execution
- Evaluation: navigation performance metrics

## Technology Stack

- Python
- OpenCV
- NumPy
- Matplotlib
- pytest
